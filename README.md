## ⚙️ Створення віртуального середовища

Рекомендується використовувати віртуальне середовище `.venv`. Воно дозволяє ізолювати бібліотеки цього проєкту від інших Python-проєктів.

Відкрийте термінал у VS Code:

```text
Ctrl + `
```

### Windows (PowerShell)

Створіть віртуальне середовище:

```powershell
python -m venv .venv
```

Активуйте його:

```powershell
.venv\Scripts\Activate.ps1
```

Якщо PowerShell повідомляє про заборону виконання скриптів, виконайте:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Після цього повторіть команду активації.

**Альтернатива для CMD:**

```cmd
.venv\Scripts\activate.bat
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Перевірка активації

Якщо все виконано правильно, на початку рядка термінала з'явиться позначка:

```text
(.venv)
```

## 📊 Очікувані результати

Після успішного виконання всіх комірок Jupyter Notebook ви отримаєте:

- Інформацію про встановлені версії бібліотек.
- Таблицю з описом набору даних, який містить **300 об'єктів**.
- П'ять графіків для візуального аналізу результатів експерименту.
- Таблицю з метриками моделі Random Forest.
- Підсумкову порівняльну таблицю трьох моделей машинного навчання.

### Основні графіки

1. **Розподіл класів (Class Distribution)** — демонструє кількість об'єктів кожного класу.
2. **Матриця помилок (Confusion Matrix)** — показує правильні та неправильні класифікації.
3. **Вплив гіперпараметрів (Hyperparameter Tuning)** — демонструє, як параметри впливають на результати моделі.
4. **Межі прийняття рішень (Decision Boundaries)** — візуалізує області класифікації моделі.
5. **Важливість ознак (Feature Importance)** — показує, які ознаки найбільше впливають на прогнозування.

## 🏆 Результати Random Forest

За результатами попереднього експерименту модель Random Forest продемонструвала такі показники:

| Метрика | Результат | Опис |
|---|---:|---|
| Accuracy | **0.933** | Загальна точність класифікації |
| F1-score | **0.915** | Гармонійне середнє Precision та Recall |

### Інтерпретація результатів

- **Accuracy = 0.933** — модель правильно класифікувала приблизно 93,3% об'єктів.
- **F1-score = 0.915** — показник, який враховує баланс між Precision та Recall.

> **Примітка:** наведені результати отримані під час попереднього запуску з використанням `scikit-learn 1.8.0`. На іншому комп'ютері показники можуть дещо відрізнятися залежно від версії бібліотек, параметрів середовища та випадкових процесів у моделі.

**Важливо:** якщо після запуску експерименту показники метрик змінилися, необхідно оновити їх у презентації, звіті та тексті доповіді.

## 🛠️ Можливі проблеми та їх вирішення

| Проблема | Спосіб вирішення |
|---|---|
| `ModuleNotFoundError: No module named 'sklearn'` | Перевірте, чи вибрано ядро `.venv`. За потреби повторно встановіть бібліотеки в активному середовищі. |
| Python не знайдено | Перевірте, чи додано Python до системного `PATH`. |
| Kernel не відображається | Переконайтеся, що встановлено `ipykernel`, після чого перезапустіть VS Code. |
| Графіки не відображаються | Перевірте вибране ядро та повторно виконайте відповідну комірку. |
| Українські літери відображаються квадратиками | Оновіть `matplotlib` або налаштуйте відповідний шрифт, наприклад DejaVu Sans. |
| Блокнот довго виконує обчислення | Дочекайтеся завершення підбору гіперпараметрів. Це може бути нормальною поведінкою. |
